# Your brand pack

Put your brand here (this folder is Git-ignored except this file): `brand.toml`, `tokens.json`,
`fonts.toml`, `voice.md`, `graphic-language.md` and `logos/`. Until `brand.toml` exists, the agent
uses the sample brand in `examples/brands/example-studio/`.

Start from the sample with `uv run design-agent brand init`, or have your coding agent follow the
[brand-onboarding skill](../../.agents/skills/brand-onboarding/SKILL.md). Check it with
`uv run design-agent brand validate`.
