# Incredible.dev 0.1.0

The first release of the new Incredible.dev: developer content made from the material you already
have. Channels and threads where agents research, storyboard and make films, cards and posts; a
canvas to review them on; and, new in this release, **episodes**: presenter-led explainers taken
from your notes to a rendered film, made chapter by chapter in a studio of their own, and a
**production board** to run many of them at once.

## Episodes

- **From notes to a plan.** Start from your notes or a research frame. The agent you pick (Claude
  Code, Codex or Kimi Code on your computer, or the built-in agent) writes the plan in stages: the
  brief, the script (chapters and their beats) and a frame for every line. Code checks each stage
  before the next, and you approve the plan once. Ask for a length as a range, and the script lands
  inside it.
- **The studio.** Each chapter is a document you edit as text, with the frame for the line you are
  on and the chapter's timeline. Ask AI on a line, a selection, a picture or the chapter; every
  change is marked word by word and can be taken back. Picks are free to try and run nothing until
  you apply them.
- **Pictures.** Each picture is a HyperFrames composition in your brand, built by a coding agent and
  held to the renderer's own checks. Simple pictures are drawn at once; motion graphics are planned
  shot by shot, looked over by their builder, and wait for your go on a still of each line. Pick the
  agent for the film, a chapter or one beat, and the model and effort it runs on. A picture's card
  names the beats it plays over.
- **Live agent trails.** Every build shows its stages and steps and, between steps, what the model
  is doing: thinking, with the newest words of its thought, or the file it is writing and how much
  so far. Its marks move only while the agent is heard from, and a turn that goes silent too long
  says so, with Stop. Leave a note for a motion-graphics picture's builder without stopping it.
- **Versions.** A beat keeps its last twelve versions. The History tab shows them and Use this
  version puts one back. A redo never blocks the studio, and one that fails or is stopped falls
  back to the version before.
- **Recording and voice.** Record each chapter in the browser with a reading guide, or bring a
  camera's file. Your take sets when each line and each picture's moves land. Name takes, review one
  before saving it, and pick the one the film uses. Lines no take covers can be narrated in a voice
  you pick or a clone of your own (with an ElevenLabs key).
- **The film.** One HyperFrames page written by code and rendered on the thread's computer, as a
  draft with a stand-in before anything is recorded; download it from the studio.

## The production board

One place to run every episode: what is written and not made (by episode and chapter), each
agent's running and waiting jobs, what needs you (a go on stills, a plan to read, a job that
stopped), and what is done. Hand a job, a chapter or a whole episode to an agent by dragging it onto
the agent's row, with the agent's number key, or from the job's details, on the model and effort
picked for that agent; the row says what that comes to before you let go. Narrow the board to an
episode, a chapter or an agent (the address keeps it), open an episode as a peek over the board, or
go to its own page at the job's chapter and line. An agent builds at most four pictures at once
across all episodes; the rest wait their turn.

## Also in this release

- **Channels, threads and the canvas.** Templates (Launch kit, Explainer, Post to social, Ad set,
  Pitch pack, Social pack, Talk to clips), storyboards with notes and sign-off, films built with
  HyperFrames, thumbnails, social cards and GIFs, each linked to what it was made from and with an
  address of its own.
- **Research frames.** Ask Claude Code, Codex or Kimi Code about a repository, read-only, and keep
  passages of their answers as notes that feed what gets made.
- **Brands.** Create a brand from a website or keep a brand pack, and pick one per channel.
- **A record of every agent run.** Each run of a coding agent is kept with its steps, and a session
  an agent has lost is retold from that record.

## Good to know

- The app has no sign-in yet. It serves 127.0.0.1 only; don't expose it on a network.
- Coding agents run as you, with your own sign-in and plan, and get none of the app's keys.
- Claude Code says what it is thinking as it goes. Codex and Kimi Code report only finished steps,
  so their trails show them as quiet while they think.
- An agent's turn on an episode stops after 30 minutes.
